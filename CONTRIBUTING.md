# Contributing to MoneyOS

## Getting Help
- Join our Discord community
- File an issue in GitHub
- Ask questions on Stack Overflow (tag: moneyos-financial-engine)

## Code of Conduct
Contributors are expected to follow our [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md)

## Development Workflow
1. Fork the repository
2. Create a feature branch (`git checkout -b feature/new-feature`)
3. Commit changes with descriptive messages
4. Push to your fork and open a pull request
5. Code reviews before merging

## Commit Guidelines
- Use imperative mood (e.g., "fix bug", not "fixed bug")
- Write clear commit messages
- Keep changes focused and small

## Testing
- All features must have unit tests
- Integration tests for critical paths
- Use `npm test` to run tests

## Code Style
- Follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) guidelines
- Use Prettier for code formatting
- Enforce TypeScript best practices

## Documentation
- API documentation in `/docs/api`
- User documentation in `/docs/user`
- Developer documentation in `/docs/dev`

## Pull Request Process
1. Ensure all tests pass
2. Update documentation if needed
3. Request review from maintainers
4. Address feedback promptly
5. Merge after approval

## Issue Reporting
- Use the provided issue templates
- Include steps to reproduce
- Specify expected vs actual behavior
- Include environment details

## Security
- Report security issues privately
- Do not expose secrets in code
- Follow secure coding practices
