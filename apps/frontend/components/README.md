# components/

Reusable, presentational, feature-agnostic components.

- `ui/` — shadcn/ui primitives (buttons, inputs, dialogs).
- `layout/` — App shell, navigation, headers, footers.
- `charts/` — Reusable chart/visualization wrappers.
- `common/` — Generic shared components used across features.

Feature-specific components live under `features/<feature>/`.
