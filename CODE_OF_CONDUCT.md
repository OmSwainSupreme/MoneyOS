# MoneyOS Code of Conduct

## Our Pledge
We pledge to make contributing to MoneyOS an inclusive and respectful experience for everyone, regardless of race, ethnicity, gender, sexual orientation, religion, or disability.

## Expected Behavior
- Be respectful in all interactions
- Welcome new contributors
- Address issues professionally
- Respect diverse perspectives
- Use welcoming and inclusive language
- Be open to different viewpoints and experiences
- Accept constructive criticism gracefully
- Focus on what is best for the community

## Unacceptable Behavior
- Harassment of any kind, including sexualized language or imagery
- Trolling, insulting, or derogatory comments
- Public or private harassment
- Publishing others' private information without explicit permission
- Not respecting differing opinions, beliefs, or experiences
- Use of sexualized language or imagery in any communication
- Exclusionary practices
- Use of offensive language or slurs
- Any other conduct which could reasonably be considered inappropriate in a professional setting

## Reporting Concerns
If you experience any unacceptable behavior:
1. Contact maintainers privately at conduct@moneyos.com
2. File a GitHub issue with the "conduct" label
3. Escalate to project steward if needed
4. All reports will be reviewed and investigated promptly

## Enforcement
Violations may result in:
- Warning for first offense with explanation of why behavior was inappropriate
- Temporary ban from community interaction for repeated or serious offenses
- Permanent ban from community for severe or repeated violations
- Removal of contributed content that violates this code

## Scope
This Code of Conduct applies to all community spaces, including:
- GitHub repositories
- Issue trackers
- Pull requests
- Documentation
- Community forums
- Social media channels
- Events and meetups
