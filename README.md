# MoneyOS
## Project Vision
MoneyOS is an AI-powered Financial Decision Engine that helps users make confident financial decisions by analyzing financial data and answering questions such as:
- Can I buy this bike?
- Should I take this loan?
- Where am I overspending?
- How can I improve my financial health? 

## Technologies
- **Frontend:** Next.js, TypeScript, Tailwind CSS, shadcn/ui
- **Backend:** FastAPI, Python, PostgreSQL
- **Infrastructure:** Docker, Docker Compose
- **Development Tools:** Git, GitHub, TypeScript

## Setup Instructions
1. Clone the repository
2. Run `./scripts/setup.sh` to initialize project dependencies
3. Build and run with `docker-compose up`
